## Вывод

Для 32 включённых CVE найдены 15 отчётов на GitHub Gist, 12 заявок через VulDB, 2 бюллетеня GHSA PyTorch и 2 исходных сообщения в GitHub issue; для одной записи канал не установлен. Преобладание авторских отчётов и заявок показывает, что значительная часть выборки описана вне бюллетеней разработчика, причём 12 CVE связаны с отчётами одного автора — Shaoyu Yang. 

## Медиана числа дней от исправления до публикации

Среди 23 записей с подтверждённым исправленным релизом медиана числа дней от исправления до публикации составляет 50 дней: у 14 CVE релиз предшествовал публикации, у 9 вышел позднее; ещё для 9 CVE исправленный релиз не установлен, и в расчёт они не вошли.

## Как определён канал

`channel` — площадка публичного отчёта об уязвимости: бюллетень разработчика, принятая заявка в VulDB или авторская публикация. Если отдельного отчёта не найдено, учитывается исходное сообщение об ошибке в GitHub issue. Для каждой CVE выбран один канал; это не обязательно первая публикация об ошибке и не свидетельство того, каким способом исследователь связался с разработчиком непублично. Например, у Shaoyu Yang сначала появились GitHub issues, а затем отдельные отчёты о CVE в Gist — в подсчёте использованы отчёты.

`reporter` — исследователь, явно указанный в благодарностях или разделе Discoverer, заявитель из записи CNA либо автор исходного сообщения об ошибке. Заявитель CVE не обязательно первым обнаружил ошибку. Владение страницей Gist и авторство исправляющего коммита сами по себе не подтверждают имя исследователя.

## Примеры публикаций, на момент которых исправления ещё не было

- [CVE-2022-45907](https://www.cve.org/CVERecord?id=CVE-2022-45907) опубликована 26.11.2022, а исправленная [версия 1.13.1](https://pypi.org/project/torch/1.13.1/) появилась на PyPI 15.12.2022 — через 19 дней.
- [CVE-2025-2953](https://vuldb.com/cve/CVE-2025-2953) опубликована 30.03.2025; исправленная [версия 2.7.1](https://pypi.org/project/torch/2.7.1/) вышла 04.06.2025 — через 66 дней.
- [CVE-2025-2998](https://www.cve.org/CVERecord?id=CVE-2025-2998) и [CVE-2025-2999](https://www.cve.org/CVERecord?id=CVE-2025-2999) опубликованы 31.03.2025; исправленная [версия 2.10.0](https://pypi.org/project/torch/2.10.0/) вышла 21.01.2026 — через 296 дней.

`fix_date` — дата публикации первой подтверждённой исправленной стабильной версии `torch` на PyPI (UTC, по первому опубликованному wheel). Версия подтверждается бюллетенем разработчика или сравнением исправления с кодом релизов
